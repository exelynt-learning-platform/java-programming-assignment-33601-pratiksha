## 7. Understanding Origin and Main

### Origin

Origin is the default name for a remote Git repository. It usually points to the repository hosted on GitHub.

### Main

Main is the primary branch of a Git repository. It generally contains the stable project code.

### Origin/Main

Origin/main represents the main branch on the remote GitHub repository.

## 8. Real Team Git Workflow

In a real development team, developers follow these steps:

1. Pull: Get the latest changes from the remote repository.

   `git pull origin main`

2. Branch: Create a separate branch for a new feature.

   `git checkout -b feature/weather-update`

3. Commit: Save changes locally.

   `git add .`

   `git commit -m "Add weather update"`

4. Push: Upload the feature branch to GitHub.

   `git push -u origin feature/weather-update`

5. Pull Request: Create a Pull Request on GitHub to request code review and merging into main.

6. Review: Team members review the code and suggest improvements.

7. Merge: After approval, merge the Pull Request into main.

8. Pull Again: Update the local main branch.

   `git switch main`

   `git pull origin main`

## Conclusion

GitHub synchronization allows multiple developers to work on the same project. Git pull, branch, commit, push, and Pull Requests help maintain an organized development workflow.
