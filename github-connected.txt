## Local Repository vs Remote Repository

Local Repository:
A local repository is stored on my computer. It contains project files, branches, and commit history.

Remote Repository:
A remote repository is hosted on GitHub. It allows developers to share code, collaborate, and access the project online.

Git commands:
- git commit: Saves changes locally.
- git push: Uploads local commits to GitHub.
- git pull: Retrieves and integrates remote changes.
- git fetch: Downloads remote updates without merging them.
