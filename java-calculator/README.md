
# Java Calculator

## Overview
A simple command-line calculator developed using Java.
It supports basic arithmetic operations.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Modulus (%)
- Input validation
- Division by zero handling
- Menu-driven interface

## Technologies
- Java
- Git
- GitHub
- VS Code

## Project Structure

java-calculator/
├── src/
│   └── Calculator.java
├── .gitignore
└── README.md

## Requirements
- JDK 17 or later
- Git

## How to Compile

Open the terminal in the project directory.

```bash
javac -d out src/Calculator.java
```

## How to Run

```bash
java -cp out Calculator
```

## Sample Program Run

===== Java Calculator =====
Enter first number: 10
Enter operator (+, -, *, /): +
Enter second number: 20
Result: 30.0
